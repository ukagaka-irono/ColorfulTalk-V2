# 声データ形式（`.ctv`、ColorfulTalk V2）

V2 の声の種類を決めるデータです。上限は 16KB（16,384 バイト）で、現在の形式（版 1）は 1 つ 212 バイトです。
数値はすべてリトルエンディアン、詰め物はありません。エンジンは 1 バイトずつ読むので、どの番地に置いてもかまいません。

## 全体（版 1）

| オフセット | 大きさ | 内容 |
|---|---|---|
| 0 | 64 | ヘッダ |
| 64 | 20 | ブロック 0: 声の基本 |
| 84 | 128 | ブロック 1: 音源（int16 × 64） |

ブロックの位置はヘッダの目次で決まります。上の並びは `mkvoice` が作るときの並びです。

## ヘッダ（64 バイト）

| オフセット | 型 | 内容 |
|---|---|---|
| 0 | char[4] | マジック `CTV2` |
| 4 | uint16 | 形式の版（1） |
| 6 | uint16 | ヘッダの大きさ（64） |
| 8 | uint32 | ファイル全体の大きさ（64〜16384） |
| 12 | uint32 | CRC-32（IEEE 802.3。この 4 バイトを 0 として全体から計算） |
| 16 | char[16] | 声の名前（ASCII、NUL 埋め、最大 15 文字） |
| 32 | uint16 × 8 | ブロックの位置。[0] 声の基本、[1] 音源、[2]〜[7] 予約（0） |
| 48 | uint8 × 16 | 予約（0） |

## ブロック 0: 声の基本（20 バイト）

| オフセット | 型 | 内容 | 範囲 |
|---|---|---|---|
| 0 | uint16 | 基準 F0 [Hz] | 40〜600 |
| 2 | uint8 | 抑揚の幅 ×1/64（64 = 標準） | |
| 3 | uint8 | ささやき声（1 = 声帯を振動させない） | 0〜1 |
| 4 | uint16 | 声道の長さの倍率 Q12（4096 = 1.0） | 2048〜8192 |
| 6 | uint8 | B1（第 1 フォルマントの帯域幅）の追加 [Hz] | |
| 7 | uint8 | 声帯音源の高域減衰（1 次ローパスの係数 Q8） | |
| 8 | uint8 | 母音に混ぜる気息音 [dB]（60 = 母音と同じ強さ。0 = なし） | |
| 9 | uint8 | 声のゆらぎ ×1/1024 | |
| 10 | uint16 | 出力ゲイン Q8 | |
| 12 | uint8 | 声門が閉じる位置 ×1/64 周期 | 1〜63 |
| 13 | uint8 | 音源の点数（版 1 では 64） | 64 |
| 14 | uint8 × 6 | 予約（0） | |

## ブロック 1: 音源

LF モデルの声門体積流 1 周期を 64 点にしたもの（int16、Q14、ピーク 16384）。

## 検査

`ct2_voice_check()` と `ct2_start()` は次を確かめ、合わなければ `CT_ERR_VOICE` を返します。

- マジック・形式の版・ヘッダの大きさ
- ファイル全体の大きさ（`ct2_voice_check` では渡された大きさ以下か）
- CRC-32
- ブロックがファイルの中に収まっているか
- 上の表の「範囲」

## 作り方

`tools/mkvoice` で、声の高さ・声道の長さ・Rd などから作ります（[README](../README.md#声を作る)）。

## 互換性

- 形式の版が上がっても、エンジンは古い版の声データを読めるようにします
- 知らないブロック（予約番号）は読み飛ばします
