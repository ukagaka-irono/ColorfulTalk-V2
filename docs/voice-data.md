# 声データ形式（`.ctv`、ColorfulTalk V2）

> 状態: 案。V2 の実装時に確定します。

V2 の声の種類を決めるデータです。1 ファイル 16KB（16384 バイト）以下。
数値はすべてリトルエンディアン、構造体の詰め物はなし。

## 全体

| オフセット | 大きさ | 内容 |
|---|---|---|
| 0 | 64 | ヘッダ |
| 64 | 可変 | 各ブロック（ヘッダの目次に従う） |

## ヘッダ

| オフセット | 型 | 内容 |
|---|---|---|
| 0 | char[4] | マジック `CTV2` |
| 4 | uint16 | 形式の版（1） |
| 6 | uint16 | ヘッダの大きさ（64） |
| 8 | uint32 | ファイル全体の大きさ |
| 12 | uint32 | CRC-32（12〜15 バイト目を 0 として全体を計算） |
| 16 | char[16] | 声の名前（ASCII、NUL 埋め） |
| 32 | uint16 × 8 | ブロックの目次（各ブロックの先頭オフセット。0 はなし） |
| 48 | uint8 × 16 | 予約（0） |

## ブロック（目次の順）

| 番号 | ブロック | 内容 |
|---|---|---|
| 0 | 声の基本 | 基準 F0（Hz×16）、抑揚の幅、声道倍率（Q12）、Rd、気息、ゆらぎ、音量補正 |
| 1 | 音源表 | LF パルス 1 周期（int16 × 128）。必要なら Rd 別に複数 |
| 2 | 母音 | 5 母音の F1〜F3・B1〜B3（Hz） |
| 3 | 子音 | 子音ごとの長さ・雑音の共振器（周波数・帯域・振幅）・ローカス |
| 4 | 韻律 | モーラ長、句末の伸長、休止の長さ、藤崎モデルの係数 |
| 5〜7 | 予約 | |

各ブロックの細かい並びは、V2 の実装（`include/colorful_talk_v2_voice.h`）で定義し、このページに追記します。

## 互換性

- 形式の版が上がっても、エンジンは古い版の声データを読めるようにする
- 知らないブロック（予約番号）は読み飛ばす
